# Karakter görselleri (2D yüzler)

Buraya oyundaki karakterin **2D yüz görsellerini** koyabilirsin. Eklediğinde
3D karakterin yüzüne doku (texture) olarak veya 2D yüz katmanı olarak bağlarım.

## Adlandırma (çağ başına bir yüz)

Dosyaları çağ kimliğiyle adlandır (PNG, kare, saydam arka plan, ~256–512px):

```
stone.png        Taş Devri
hunter.png       Avcılık Çağı
agri.png         Tarım Devrimi
antiquity.png    Antik Çağ
medieval.png     Orta Çağ
renaissance.png  Rönesans
industrial.png   Sanayi Devrimi
info.png         Bilgi Çağı
space.png        Uzay Çağı
galactic.png     Galaktik Çağ
```

Tek bir genel yüz istersen `face.png` koy; hepsinde onu kullanırım.

## ⚠️ Lisans — ÖNEMLİ (public repo)

Bu repo **herkese açık**. Buraya **yalnızca**:
- kendi çizdiğin/ürettiğin görselleri, veya
- **CC0 / kamu malı** (ör. Kenney.nl) görselleri koy.

**Koyma:** CraftPix "ücretsiz" varlıkları, Google'dan bulduğun rastgele
görseller, telifli/lisanslı setler. Bunların public repoda yeniden dağıtımı
lisans ihlali olur (hukuki/itibar riski).
